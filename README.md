# OIBSIP Data Science Task 3 – Car Price Prediction with Machine Learning

## 📌 Project Overview

This project is completed as part of the OASIS INFOBYTE Data Science Internship.

The objective of this project is to build a machine learning model that predicts the selling price of used cars based on different vehicle characteristics.

## 🎯 Objectives

- Clean and prepare the car price dataset.
- Calculate car age from the manufacturing year.
- Extract the car brand from the car name.
- Analyze car selling prices using exploratory data analysis.
- Encode categorical variables using one-hot encoding.
- Analyze feature correlations.
- Train regression models to predict car selling prices.
- Evaluate the models using MAE, RMSE, and R² Score.
- Analyze feature importance using Random Forest.
